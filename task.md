Car Price Prediction (Machine Learning & Web Deployment)
The Goal: Predict car selling prices based on attributes like fuel type, kilometers driven, previous owners, and transmission type
.
Key Technical Steps: You will perform feature engineering (like deriving "years since manufacture"), optimize hyperparameters using RandomizedSearchCV, and train a Random Forest Regressor
.
Standout Feature: You must take this model beyond a notebook and deploy it as a web application or API using Flask, allowing users to input car details and get live price estimates
